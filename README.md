# Legal Lounge website

This repository holds the Legal Lounge website. The whole site is a single file, `index.html`.

## Publish with GitHub Pages

1. Upload `index.html` and `.nojekyll` to the root of this repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*, choose the `main` branch and the `/ (root)` folder, then click **Save**.
4. After a minute or two the site is live at `https://<your-username>.github.io/<repository-name>/`.

## Use your own domain (optional)

1. In **Settings → Pages → Custom domain**, enter your domain (for example `www.legallounge.co.zw`) and save.
2. At your domain registrar, add a CNAME record pointing `www` to `<your-username>.github.io`.
3. Tick **Enforce HTTPS** once it becomes available.

## Updating the site

Replace `index.html` with the new version and commit. GitHub Pages republishes automatically.
